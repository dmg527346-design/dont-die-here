# Don't Die Here

Source code for **Don't Die Here**, a multiplayer horror game on Roblox built around cursed items.

Play it: https://www.roblox.com/games/86808802596548/Dont-Die-Here

- `src/` mirrors the game's scripts by Roblox service (ServerScriptService, ReplicatedStorage, StarterPlayer, ...).
- Written in Luau, built with Claude as a coding partner.

This repository is private. Place files, assets and player data are not included.
